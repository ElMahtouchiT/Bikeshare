🔐 Double authentification

✅ La double authentification est activée sur votre compte. À chaque connexion, un code de votre application Authenticator vous sera demandé.

  1. Installez Microsoft Authenticator (ou Google Authenticator) sur votre téléphone.
  2. Scannez le QR code ci-dessous, ou saisissez la clé manuellement.
  3. Entrez le code à 6 chiffres affiché par l'application pour confirmer.
